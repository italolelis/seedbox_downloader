  <name>Task 1: Strip file extension from basePath in getFilesRecursively for single-file transfers</name>
  <files>internal/dc/putio/client.go</files>
  <action>
In `getFilesRecursively`, the bug occurs when the root node is a single file (not a directory).
The function is called from `GetTaggedTorrents` as:

```go
files, err := c.getFilesRecursively(ctx, file.ID, file.Name)
```

Where `file.Name` is `"the_movie.mkv"`. The function then builds:

```go
Path: filepath.Join(basePath, file.Name)
// = filepath.Join("the_movie.mkv", "the_movie.mkv")
// = "the_movie.mkv/the_movie.mkv"  <-- WRONG
```

The fix: extract a private helper `stripFileExtension(name string) string` that returns
`strings.TrimSuffix(name, filepath.Ext(name))`. Then, inside the `!file.IsDir()` branch at
the top of `getFilesRecursively`, strip the extension from `basePath` before using it:

```go
if !file.IsDir() {
    folderName := stripFileExtension(basePath)  // "the_movie.mkv" -> "the_movie"
    result = append(result, &transfer.File{
        ID:   file.ID,
        Path: filepath.Join(folderName, file.Name),  // "the_movie/the_movie.mkv"
        Size: file.Size,
    })
    return result, nil
}
```

Edge cases (per user decisions in CONTEXT.md):
- Multiple dots: `the.movie.2024.mkv` -> `strings.TrimSuffix("the.movie.2024.mkv", ".mkv")` = `"the.movie.2024"` — correct, `filepath.Ext` only strips the last segment.
- No extension: `filepath.Ext("movie")` returns `""`, so `TrimSuffix("movie", "")` = `"movie"` — folder stays `"movie/"`, file inside `"movie/movie"`. Correct (no crash, sensible behavior).
- Hidden files starting with dot: `filepath.Ext(".hidden")` returns `""`, folder stays `".hidden"`. Acceptable per user decisions (no special handling required).

The `stripFileExtension` helper should be placed near the end of the file alongside other private helpers (`findDirectoryID`, `filterMatchingTransferIds`). Add a GoDoc comment.

The multi-file path (where `file.IsDir()` is true and the function recurses) is UNTOUCHED — no change to `filepath.Join(basePath, f.Name)` for directory traversal.

Imports: `strings` is already imported. `filepath` is already imported. No new imports needed.

Do NOT rename or refactor any other function. Do NOT change `GetTaggedTorrents`. Only modify `getFilesRecursively` and add the `stripFileExtension` helper.

```go
func TestGetFilesRecursively_SingleFileExtensionStrip(t *testing.T) {
    tests := []struct {
        name         string
        fileName     string
        fileType     string
        expectedPath string
    }{
        {
            name:         "mkv single file",
            fileName:     "the_movie.mkv",
            fileType:     "VIDEO",
            expectedPath: "the_movie/the_movie.mkv",
        },
        {
            name:         "mp4 single file",
            fileName:     "movie.mp4",
            fileType:     "VIDEO",
            expectedPath: "movie/movie.mp4",
        },
        {
            name:         "multiple dots mkv",
            fileName:     "the.movie.2024.mkv",
            fileType:     "VIDEO",
            expectedPath: "the.movie.2024/the.movie.2024.mkv",
        },
        {
            name:         "no extension",
            fileName:     "movie",
            fileType:     "VIDEO",
            expectedPath: "movie/movie",
        },
    }

    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            mux := http.NewServeMux()
            mux.HandleFunc("/v2/files/100", func(w http.ResponseWriter, r *http.Request) {
                w.Header().Set("Content-Type", "application/json")
                fmt.Fprintf(w, `{"file":{"id":100,"name":%q,"size":1000,"file_type":%q,"content_type":"video/x-matroska"}}`,
                    tt.fileName, tt.fileType)
            })
            server := httptest.NewServer(mux)
            defer server.Close()

            client := newTestClient(server.URL)
            files, err := client.getFilesRecursively(context.Background(), 100, tt.fileName)

            require.NoError(t, err)
            require.Len(t, files, 1)
            assert.Equal(t, tt.expectedPath, files[0].Path)
        })
    }
}
```
